```bash
npm run storybook   # dev, http://localhost:6006
npm run build-storybook  # static build → storybook-static/
```

## Structure

| Folder | What's inside |
|---|---|
| `components/atoms/` | shadcn-based primitives restyled to Eque tokens (Button, Input, Select, …) |
| `components/molecules/` | Composed components (StatCard, TokenAmountInput, …) |
| `components/organisms/` | Wallet & transaction flows (Phase 3) |
| `components/templates/` | Page shells (Phase 6) |
| `lib/` | `cn()`, formatters, typed mock data |

## Tokens at a glance

| Token | Value | Use |
|---|---|---|
| `--color-canvas` | `#070A0F` | Page background |
| `--color-primary` | `#1FFFC3` | Brand teal — actions, highlights |
| `--color-surface` | `#0D141D` | Card / panel surface |
| `--color-text-primary` | `#F2F7F5` | Headings, key figures |
| `--radius` | `0px` | Sharp by default (`sm` = `0.25rem` only) |

Fonts: **Spline Sans Mono** for headings, labels, buttons and numbers ·
**Google Sans** for body text.

## Rules that matter

- No raw hex in components — every color comes from a token.
- Status is never color alone: pair it with a glyph or label.
- Token, network and avatar imagery are out of scope — text and
  consumer-supplied `iconSrc` URLs only.
- Every component ships with interaction tests in its stories file.
